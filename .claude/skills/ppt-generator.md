# PPT Generator Skill - 智能战友PPT生成器

## 概述

使用三重AI模型协作生成专业商业PPT:
- **Gemini 3 Pro Preview**: PPT框架、结构、大纲设计
- **Claude Opus 4.5**: 内容填充、文案润色
- **Gemini 2.0 Flash**: 8K超高清图像渲染

## 使用方法

### 快速生成PPT

```bash
# 进入PPT生成器目录
cd skills/ppt-generator/python

# 安装依赖
pip install -r requirements.txt

# 生成PPT
python intelligent_ppt_strategist.py -t "报告主题" -c "内容描述"
```

### 完整参数

```bash
python intelligent_ppt_strategist.py \
  -t "2025年Q1业绩分析报告" \
  -c "销售额6.55亿，增长546%，直播占比76%" \
  -a "c_suite" \
  -g "report" \
  --no-prediction  # 跳过效果预判(可选)
```

### 从仪表盘数据生成

```bash
python intelligent_ppt_strategist.py -d --from-dashboard
```

## 参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| `-t, --topic` | 报告主题 | "Q1业绩分析" |
| `-c, --content` | 内容描述 | "销售额增长50%" |
| `-a, --audience` | 受众类型 | c_suite/investors/clients |
| `-g, --goal` | 演示目标 | report/pitch/persuade |
| `-d, --from-dashboard` | 使用仪表盘数据 | - |
| `--no-analysis` | 跳过智能分析 | - |
| `--no-prediction` | 跳过效果预判 | - |

## 受众类型

- `c_suite`: CEO/CFO/CTO等高管
- `board`: 董事会
- `investors`: 投资人/VC/PE
- `clients`: 客户/甲方
- `internal`: 内部团队
- `government`: 政府/监管
- `sales`: 销售场景
- `training`: 培训场景

## 演示目标

- `report`: 汇报工作
- `pitch`: 融资路演
- `persuade`: 说服获取支持
- `inform`: 传达信息
- `teach`: 教学培训
