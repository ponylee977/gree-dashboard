# /ppt - 智能战友PPT生成器

使用三重AI模型协作生成专业商业PPT：
- Gemini 3 Pro: PPT框架结构设计
- Claude Opus 4.5: 内容填充润色
- Gemini 2.0 Flash: 8K图像渲染

## 使用方法

用户输入主题后，运行以下命令生成PPT：

```bash
cd $PROJECT_ROOT/skills/ppt-generator/python && python intelligent_ppt_strategist.py -t "$ARGUMENTS"
```
